# Workout Diary 📔
# Made by Arpit Yadav 
A simple iOS workout tracker built with **SwiftUI** and **SwiftData**.

Workout Diary is designed to make logging workouts quick and keep your training history organized.

## ✨ Features

* 🏋️ Create and manage workouts
* 💪 Add exercises and log sets
* 📊 Record weight and reps
* 🗂️ View workout history
* 💾 Persistent local storage with SwiftData
* 🧭 Simple SwiftUI navigation

## 🛠️ Built With

* **Swift**
* **SwiftUI**
* **SwiftData**
* **Xcode**

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in Xcode.
3. Select a simulator or connected iPhone.
4. Build and run with **⌘R**.
